## Features

### Initial Adminstrator User
If the system does not have an administrator user, it will prompt the user to create the first administrator user.  This user will be identified by email address and password.  

### Application Windows
Applications may only be selected if an Application Window has been created by an administrator user.  Application Windows may be of 2 types:  Testing, and Live (for accepting real world applications). Applications Windows will have a unique name such as:  "Testing Series A", or "2026 Scholarship Applications".  Testing windows are not available to the general public, and can only be used by reviewers for testing purposes.

If a Live Application Window is not active (based on start and end dates), then external users will not be able to create accounts or submit applications. 

### Account Creation
All accounts created in the system should be identified by an email address and a password.  All new account creations should perform an email verification check using a random 6-digit number.  With the exception of the first administrator user, all new accounts will have a default type of 'Applicant'.  

### Account Management
Every account should have the ability to create an account profile. This may contain basic contact information such as:  First, Middle, and Last Name, Email Address, Phone Number, and Home Address.  All account users should have the ability to change their password.  They should also have the ability to reset their password by email verification.
