# Beaverton Rotary Foundation Scholarships

## Overview
Each year, the Beaverton Rotary Foundation accepts applications for scholarships.  There are 4 distinct types of scholarships available: Academic, Academic Renewal, CEYP, and Vocational.



Beaverton Rotary Scholarship Committee members review the applications and present their recommendations to the Beaverton Rotary Foundation for review and acceptance.  Once accepted, each applicant receives money, dispersed by the Beaverton Rotary Foundation Treasurer to the school of their choice to offset tuition, books, or other fees. 

## Objective
Create a modern web application that has the following key features.

- Enables applicants to submit data to be reviewed as an application for a scholarship.  
- Enables Beaverton Rotary Foundation scholarship committee members the ability to review each application.
- Stores and tracks applications awarded each year and maintains a history of applications submitted, reviewed, and awardsed.
- Each year, provides a report on the applicants selected for one of 4 scholarships (Academic, Academic Renewal, CEYP, and Vocational).
- The application should record and track how much scholarship money was awarded to each applicant each year.

Out of scope for this project includes:

- Payments of any type.  The system will not collect or disburse funds in any manner.
